# Release 2.9 — plataforma inteligente

## Estabilidade

- pacote público gerado exclusivamente em `dist/`;
- GitHub Pages publica somente `dist/`;
- teste Playwright abre a aplicação como usuário real;
- fonte, scripts de build e dados editoriais não são expostos no artefato.

## Estudo

- painel Hoje com revisões vencidas, inéditas, ponto fraco e tentativa salva;
- revisão espaçada D0, D7 e D20;
- estatísticas por tópico: cobertura, precisão e tempo médio;
- seleção automática de pontos fracos;
- simulado equilibrado por cargo com aviso de que não substitui a distribuição oficial do edital;
- diagnóstico do motivo do erro;
- anotações por questão;
- exportação CSV compatível com Anki.

## Offline

- manifesto PWA;
- instalação no celular ou desktop quando suportada;
- cache do shell, catálogo, índice e materiais já acessados;
- atualização do catálogo prioriza a rede e utiliza cache em caso de indisponibilidade.

## Privacidade

Histórico, revisão, anotações e classificação de erros permanecem no navegador e separados por perfil. Não há backend, conta ou sincronização automática entre aparelhos.
