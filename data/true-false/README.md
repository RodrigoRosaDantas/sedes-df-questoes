# Provas Certo/Errado

Esta pasta contém o índice dos lotes oficiais no formato de julgamento de itens.

A inclusão em `materials` somente ocorre depois de:

1. confirmar transcrição e gabarito;
2. identificar prova, cargo, disciplina e numeração;
3. revisar itens anulados e dependentes de imagem;
4. registrar comentário editorial ou status explícito de comentário pendente;
5. validar IDs, códigos, contagem e hashes.

O formato original da banca é preservado. Nenhum item Certo/Errado deve ser convertido para alternativas A–E.
